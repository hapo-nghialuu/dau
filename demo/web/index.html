Dấu demo · v0.1.0

Bộ gõ tiếng Việt — engine Rust chạy ngay trong trình duyệt (WASM)

Đây là engine thật của Dấu (cùng core dùng cho addon Fcitx5 trên Linux), biên dịch ra WASM để bạn thử trên macOS. UI này mô phỏng bảng cấu hình + cách hiển thị preedit (gạch chân) của bộ gõ.
